# Part 2: Stable Diffusion LoRA

[Download the Part 2 findings report](https://github.com/denishatank12/Lab-2/releases/download/lab2-submission-review/Lab2_Part2_Findings.pdf).
The three-page black-and-white report contains the measured training results,
automatic metrics, saved image comparisons and nearest-neighbor checks. It has
no fictional ratings. Real human evaluation remains pending.

`notebooks/Part2_FineTune_Run.ipynb` is the actual completed RTX 4090 experiment.
The recorded GPU cells and outputs are preserved byte for byte. Do not repeat
training just to update the report or add human ratings.

The experiment used 1,221 Naruto captioned images, split 1,098/123 with seed 266.
Two SD 1.5 LoRA runs used ranks 4 and 8, with the same data and 1,200-update
budget. The saved evaluation contains 120 images, eight comparison grids,
KID/CLIP/LPIPS, training efficiency and nearest-training-image checks.
`evidence/current_result_audit.json` records the measurements and open items.

Both adapters and the generated-image dataset were uploaded privately to
Hugging Face. Exact commits and hashes are in `evidence/hub_links.json`;
model-card copies are in `model_cards/`. Grader access and permission for the
copyrighted dataset still need confirmation. The 25-pair blinded study needs
both members and one outside rater. Team 09 and the two names are now recorded.

The combined findings are in `../REPORT.md`; the local PDF is generated by
`python tools/build_combined_report.py`. The original full result ZIP remains
in Downloads, with imported images/adapters under ignored local `outputs/`.
Those raw datasets and weights are not new Git files.

The pinned root requirements and `src/` support reproduction or recovery.
Training caches VAE/text features and optimizes only LoRA parameters.
Generation keeps the safety checker enabled and uses CPU offload.
Changed generation settings preserve prior outputs before making a new cohort;
they never label base weights as a missing adapter. The 20 regression tests
exercise these recovery and validation paths.

The recorded low optimizer-loop memory peak does not prove a complete run on
the required nominal 16-GB GPU. Keep the RTX 4090 hardware label and verify
remaining compatibility separately rather than changing the historical record.
